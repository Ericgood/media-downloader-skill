## 1. 验证原则

- 测试链接由维护者独立寻找，优先采用平台公开内容、官方开源项目 README 示例或上游 extractor 测试样本。
- “能够读取标题/元数据”不算通过，必须实际保存媒体文件。
- 视频和音频必须经过 `ffprobe`；同时记录文件大小、时长、编码、画面尺寸或采样率。
- 同一后端在相同条件下失败后不无限重试。记录错误，切换其他维护中的项目或后端。
- 自动化测试使用本地 fixture，不依赖第三方网络；真实下载作为单独的 live validation。
- 下载成品保存在 `.local/live-validation/`，由 `.gitignore` 排除；文档只保存公开源 URL 和不可逆 SHA-256，不保存带时效签名的 CDN URL。
