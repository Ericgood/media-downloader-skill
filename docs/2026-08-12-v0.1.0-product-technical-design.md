# Media Downloader v0.1.0 产品与技术设计

Created: 2026-08-12 01:18:03 CST
Last updated: 2026-08-12 01:45:34 CST
Status: Published as v0.1.0

## 1. 背景

原有 `video-downloader` Skill 以 `yt-dlp` 为主引擎，并对抖音和 X Article 添加手写 fallback。2026-08-12 的复测表明，bootstrap 当时安装的 `yt-dlp 2026.07.04` 仍无法解析当期有效的 TikTok URL，因此只更新 `yt-dlp` 不能达到可靠下载的目标。

本项目将视频下载能力升级为可持续维护的通用媒体下载器，同时覆盖 Suno、Udio 等 AI 音乐链接。

## 2. 产品目标

### 2.1 必须实现

- 下载 TikTok、抖音、X/Twitter、Bilibili、YouTube 及 `yt-dlp` 支持站点的公开视频。
- 下载 Suno、Udio 公开歌曲的原始音频，并可选保存封面、歌词和元数据。
- 支持视频、纯音频、字幕、播放列表和批量 URL。
- 在单一后端失败时自动切换到独立 fallback，并显示实际使用的后端。
- 在报告成功前通过 `ffprobe` 验证文件可播放性与媒体属性。
- 保留原 `video-downloader` 常用命令和参数的兼容性。
- 提供 `doctor` 命令诊断 Python、yt-dlp、ffmpeg 与可选后端配置。

### 2.2 明确不做

- 不绕过 DRM、付费墙、私密内容权限或平台访问控制。
- 不自动读取浏览器 Cookie；只有用户明确授权时才启用。
- 不在仓库中保存 Cookie、Token、签名下载 URL 或下载成品。
- v0.1.0 不提供图形界面和常驻下载服务。

## 3. 用户流程

1. 用户提供一个或多个公开 URL，并指定视频、音频、字幕或配套资源。
2. CLI 检测平台并选择首选后端。
3. 首选后端失败时，调度器根据平台切换 fallback。
4. 下载器将内容写入同目录临时文件，验证响应类型、文件大小和媒体流。
5. 验证成功后原子重命名为最终文件。
6. CLI 输出文件绝对路径、后端、大小、时长、编码和画面/音频属性。

## 4. 后端路由

| 平台 | 首选 | 第二级 | 第三级 |
|---|---|---|---|
| TikTok | yt-dlp | TikWM resolver | 配置的 Cobalt |
| 抖音 | yt-dlp | 本地分享页解析 | 配置的 Douyin/TikTok API |
| X/Twitter | yt-dlp | FxTwitter | 配置的 Cobalt |
| Bilibili | yt-dlp | 配置的 Cobalt | — |
| Suno | 公开歌曲页解析 | 源站 CDN | — |
| Udio | 公开歌曲页解析 | 源站 CDN | — |
| YouTube/其他 | yt-dlp | — | — |

`TikWM` 只在 TikTok 本地提取失败后接收公开 URL。Cobalt 和 Douyin/TikTok API 默认不配置，用户可连接自托管实例。

## 5. 技术架构

```text
CLI
 ├─ URL/platform detector
 ├─ request model and policy
 ├─ backend dispatcher
 │   ├─ yt-dlp adapter
 │   ├─ TikWM adapter
 │   ├─ Douyin public-page adapter
 │   ├─ FxTwitter adapter
 │   ├─ Cobalt adapter
 │   ├─ Suno adapter
 │   └─ Udio adapter
 ├─ atomic HTTP downloader
 └─ ffprobe verifier and JSON reporter
```

实现代码放在 Skill 自带的 `scripts/media_downloader/` 包中，使整个 Skill 文件夹被复制到 Codex/Claude Skills 目录后仍可独立运行。项目根目录的测试直接导入同一份代码，避免发布包与 Skill 逻辑分叉。

## 6. CLI 约定

```bash
python3 skill/media-downloader/scripts/download.py doctor
python3 skill/media-downloader/scripts/download.py info "URL" --json
python3 skill/media-downloader/scripts/download.py download "URL" --output-dir ./downloads
python3 skill/media-downloader/scripts/download.py download "URL_1" "URL_2" --output-dir ./downloads --json
python3 skill/media-downloader/scripts/download.py download "URL" --media audio --audio-format mp3
python3 skill/media-downloader/scripts/download.py subtitles "URL" --subtitle-langs en,zh-Hans
```

重要选项：

- `--backend auto|yt-dlp|tikwm|douyin|fxtwitter|cobalt|suno|udio`
- `--media auto|video|audio`
- `--resolution best|360|480|720|1080|1440|2160`
- `--cookies-from-browser BROWSER`
- `--proxy URL`
- `--with-cover`、`--with-lyrics`、`--with-metadata`、`--all-assets`
- `--json`

## 7. 安全与隐私

- 只接受 `http` 和 `https` 输入。
- 对 fallback 返回的媒体 URL 重新校验协议和主机，并在连接前拒绝不安全的重定向目标。
- 拒绝 `file:`、`data:`、localhost、环回地址和私网地址，防止把远端解析器结果变成本地文件读取或 SSRF。
- 下载到 `.part` 临时文件，设置超时和最大响应大小，验证后再重命名。
- 日志隐藏 Cookie、API Key 和 URL 查询参数中的签名值。
- 第三方 API 仅接收已经公开的帖子 URL，不上传浏览器 Cookie。
